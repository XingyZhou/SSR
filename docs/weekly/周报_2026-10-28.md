# 小波-Mamba 光谱快照重建：本周进展与结论

日期：2026-10-28 ｜ 数据：CAVE 训练 / 10 场景测试集 ｜ 任务：CASSI 28 波段重建，3-stage 展开网络

---

## 1. 本周结论（先看这一节）

1. **V7（Mamba 沿光谱维扫描）训练完成并评估：38.86 dB**，是 model_v 系列最好的一版（比 Base +0.11、V6 +0.22），但比直接对照 HyMCNetL3（空间扫描，39.12）低 0.26 dB，也略低于 SSR-S（38.93）。
2. **V7 的低频确实学到了**（优于 SSR-S 和 Base），输给 HyMCNetL3 的部分落在 16×16 到 128×128 之间的中低频，不在最低频也不在最细节。原因是 8×8 窗口内扫描丢掉了空间扫描提供的中尺度空间上下文。
3. **消融链补齐**：HyMCNetL3 → V7（扫描轴空间→光谱）−0.26。到目前为止，唯一确认有效的 Mamba 用法是「小波采样骨架 + 沿空间扫描」。
4. **主线调整**：V6（块内分频）和 V7（光谱扫描）两条支线都已有明确的负结论，主线回到 HyMCNetL3，补强消融；光谱扫描转到 Chikusei 128 波段上做最后验证。

## 3. 消融链（控制变量）

| 对比 | 唯一变化 | PSNR 变化 |
|---|---|---|
| SSR-S → Base | SSRB 块换成 MamConvB 块，其余不变 | −0.18 |
| Base → **HyMCNetL3** | 步长卷积采样换成小波采样，块不变 | **+0.37** |
| Base → V5 | 块内改为小波双支路 | −0.24 |
| Base → V6 | 块内小波双支路 + 三项编码改进 | −0.11 |
| HyMCNetL3 → **V7** | Mamba 扫描轴：空间 → 光谱 | **−0.26** |

## 4. V6 回顾：用编码补救块内低频 Mamba（已放弃）

- **假设**：V5 块内低频 Mamba 沿行优先 1D 因果扫描，上下相邻像素在序列上相距 128，看不到二维结构。
- **设计**（只改低频支路的 Mamba 输入和扫描顺序，不增加扫描方向）：(a) 四个 Haar 子带拼成 2×2 结构 token；(b) Hilbert 曲线扫描顺序，相邻 token 二维距离恒为 1；(c) Mamba 内部 1D 因果卷积换成 2D 深度卷积。参数 3.15M，初始偏差 0.072，接近恒等。
- **结果**：38.64，相对 V5 +0.13，相对 Base −0.11。
- **诊断**：把 V6 的 128×128 低频换成 HyMCNetL3 的涨 0.39 dB，只换高频涨 0.08；16×16 尺度「V5 低频 + V6 高频」（38.65）不低于 V6 自身，说明编码改动没有让低频 Mamba 学到更多结构，增益来自细节子带。
- **结论**：块内分频两轮（V5、V6）都输给不分频的 Base，放弃。

## 5. V7：沿光谱维扫描

### 5.1 思路与实现

- **动机**：CASSI 的核心耦合在光谱维；每个像素的波段序列天然有序，而空间 1D 扫描在二维图像上结构性受限。
- **设计**：相对 HyMCNetL3 只改一处。每个 MambaB 里的 `Mamba_Att`（H×W 光栅扫描）换成 `SpecMamba_Att`：特征图切成 8×8 窗口，每个窗口是一条以通道为序列、每个通道 token 为 64 个像素的序列，Mamba 沿通道（波长）扫描。空间结构交给 5×5 位置卷积、11×11 ConvB 和 U-Net 多尺度路径。骨架、小波采样、损失、训练配置均不变，所以 HyMCNetL3 与 V7 的差异只有「扫描轴」。
- **验证**：光谱因果性成立；窗口间扫描互不影响；参数 2.95M（HyMCNetL3 2.94M），一步 0.27 s、显存 10.6 GB。
- **训练**：10-19 启动，10-21 机器死机停一周，10-28 重启后从 227 轮续训，10-28 15:00 完成 300 轮。训练 PSNR 43.20（最高 280 轮 43.29）。

### 5.2 测试结果

| 轮 | PSNR | SSIM | SAM | stage1 | stage2 |
|---|---|---|---|---|---|
| 294（最佳） | 38.858 | 0.9728 | 3.961 | 35.94 | 37.91 |

- 相对 Base：scene09 +0.66、scene03 +0.47、scene02 +0.29；scene05 −0.21、scene01 −0.19、scene07 −0.13。不是全面提升。
- 训练—测试差距 4.3 dB，与 HyMCNetL3（4.27）相当，过拟合倾向没有改善。

### 5.3 频段诊断（统一用 model_300.pkl，`Result_freq3/`）

频段 SNR 相对 SSR-S 的差（dB；越大越好）：

| | LL2（最低频） | HL2 | LH2 | HH2 | HL1 | LH1 | HH1（最高频） |
|---|---|---|---|---|---|---|---|
| HyMCNetL3 | **+0.24** | −0.09 | −0.13 | −0.13 | −0.17 | −0.12 | −0.10 |
| V7 | −0.09 | −0.26 | −0.57 | −0.33 | −0.33 | −0.41 | −0.24 |
| Base | −0.21 | −0.25 | −0.37 | −0.31 | −0.30 | −0.33 | −0.28 |

- V7 的最低频 LL2 优于 Base（+0.12），但低于 SSR-S（−0.09）和 HyMCNetL3（−0.33）。
- V7 的所有细节子带都劣于 HyMCNetL3，LH2（64×64 尺度的水平边缘）最差。

子带互换（oracle，场景平均 PSNR）：

**V7 对 HyMCNetL3**（V7 38.85，HyMCNetL3 39.12）

| 低频尺度 | V7 低频 + HyMCNetL3 高频 | HyMCNetL3 低频 + V7 高频 |
|---|---|---|
| 128×128 | 38.90 | 39.07 |
| 64×64 | 38.99 | 38.97 |
| 32×32 | 39.03 | 38.93 |
| 16×16 | 39.08 | 38.88 |

**V7 对 SSR-S**（V7 38.85，SSR-S 38.93）

| 低频尺度 | V7 低频 + SSR-S 高频 | SSR-S 低频 + V7 高频 |
|---|---|---|
| 128×128 | 38.90 | 38.87 |
| 64×64 | **39.00** | 38.78 |
| 32×32 | **39.00** | 38.77 |
| 16×16 | **39.01** | 38.77 |

结论：
1. V7 低频 + SSR-S 高频同时超过两者，反过来同时低于两者：V7 的低频实打实比 SSR-S 强，拖后腿的是高频细节。模式与 HyMCNetL3 相同，但量更小（HyMCNetL3 低频 + SSR-S 高频 = 39.13）。
2. 只保留 V7 的 16×16 低频、其余用 HyMCNetL3 能到 39.08（差 0.04）；只保留 V7 最细一层细节也只损 0.05。差距分布在 16~128 的中间尺度，每上一层 V7 多亏 0.04~0.09 dB。
3. 这正是 8×8 窗口内扫描丢掉的那段空间上下文：空间扫描的 HyMCNetL3 能看全图，V7 的跨窗口信息只靠卷积。光谱建模本身没坏，坏的是空间上下文。

## 6. 对主线的含义

- 「Mamba 学全局低频」的收益来自空间扫描，光谱扫描在 28 波段上不能替代它。主线改为强调「小波采样 + Mamba（空间扫描）」，V7 作为「扫描轴」消融保留。
- V6、V7 两条支线都给出明确负结论，论文叙事可以收拢为：采样层小波 +0.37 是唯一正收益，块内分频与光谱扫描两种「更精细」的用法都不如直接在小波骨架上做空间扫描。
- 若要救 V7，方向是扩大窗口或空间 / 光谱并联，而不是改光谱侧；Chikusei 128 波段仍值得跑，那是光谱扫描真正可能发挥的地方。

## 7. 下一步计划

1. 修正 HyMCNetL3 的 FFN 双重残差单独训练一次，量化影响；补 4 / 6 stage 与 SSR-M 的同参数对比。
2. 启动 Chikusei 线（`run_chik.sh`，先 V7NB 再 NB 对照）。若光谱扫描在 128 波段上有效，再训 V7S 三档。
3. V7 救济（优先级低）：窗口 8→16 或空间 + 光谱并联扫描。
4. 论文指标用 MATLAB `cal_psnr_ssim.m` 复核 SSIM；10 场景测试集上 0.1~0.2 dB 的差异需谨慎解读。
