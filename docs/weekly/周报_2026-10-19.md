# 小波-Mamba 光谱快照重建：本周进展与结论

日期：2026-10-19 ｜ 数据：CAVE 训练 / 10 场景测试集 ｜ 任务：CASSI 28 波段重建，3-stage 展开网络

---

## 1. 本周结论（先看这一节）

1. **小波只用在上下采样层是有效的**：同一骨架下换成 Haar 采样，PSNR +0.37 dB，参数不增加。
2. **把"低频走 Mamba、高频走卷积"的分频放进块内，两轮设计（V5、V6）都输给不分频的基线**，证据已经足够，放弃这条路线。
3. **Mamba 带来的收益全部落在低频**（HyMCNetL3 比 SSR-S 多出的 0.19 dB，来自 64×64 以下的低频），这与"Mamba 学全局结构"的初衷一致，但前提是 Mamba 在"小波采样"骨架里工作，而不是在块内分频里。
4. **下一步（V7）**：保持 HyMCNetL3 骨架，只把 Mamba 的扫描轴从空间改为光谱，验证 Mamba 在 CASSI 里最合适的用法。V7 已完成实现与正确性验证，尚未训练。

## 3. 消融链（控制变量）

| 对比 | 唯一变化 | PSNR 变化 |
|---|---|---|
| SSR-S → Base | SSRB 块换成 MamConvB 块，其余不变 | −0.18 |
| Base → **HyMCNetL3** | 步长卷积采样换成小波采样，块不变 | **+0.37** |
| Base → V5 | 块内改为小波双支路 | −0.24 |
| Base → V6 | 块内小波双支路 + 三项编码改进 | −0.11 |

读法：采样层用小波是正收益；块内分频始终是负收益，V6 的三项改进只补回了 V5 差距的一半左右。

## 4. 诊断：问题出在哪个频段

### 4.1 频段 SNR 相对 SSR-S 的差（dB；越大越好）

| | LL2（最低频） | HL2 | LH2 | HH2 | HL1 | LH1 | HH1（最高频） |
|---|---|---|---|---|---|---|---|
| HyMCNetL3 | **+0.24** | −0.09 | −0.13 | −0.13 | −0.17 | −0.12 | −0.10 |
| Base | −0.21 | −0.25 | −0.37 | −0.31 | −0.30 | −0.33 | −0.28 |
| V6 | −0.34 | −0.50 | −0.59 | −0.54 | −0.50 | −0.45 | −0.35 |
| V5 | −0.45 | −0.69 | −0.60 | −0.62 | −0.63 | −0.65 | −0.47 |

- 所有模型的误差都以低频为主（LL2 占误差能量约 42%，FFT 低频环约 75%），**决定 PSNR 的是低频结构**。
- HyMCNetL3 是唯一在最低频上赢 SSR-S 的模型。
- 顺序为 HyMCNetL3 > Base > V6 > V5：**分频越深入块内，所有频段越差**，并不只是高频或只是低频的问题。

### 4.2 子带互换实验（oracle）
把两个模型重建结果的低频与细节子带交叉重组，看 PSNR 如何变化（L 越大，"低频"尺度越粗）。

**V6 对 HyMCNetL3**（V6 38.64，HyMCNetL3 39.12）

| 低频尺度 | V6 低频 + HyMCNetL3 高频 | HyMCNetL3 低频 + V6 高频 |
|---|---|---|
| 128×128 | 38.72 | **39.03** |
| 64×64 | 38.83 | 38.91 |
| 16×16 | 39.00 | 38.75 |

**V6 对 V5**（V6 38.64，V5 38.51）

| 低频尺度 | V6 低频 + V5 高频 | V5 低频 + V6 高频 |
|---|---|---|
| 128×128 | 38.59 | 38.55 |
| 16×16 | 38.49 | **38.65** |

**Base 对 HyMCNetL3**：HyMCNetL3 低频 + Base 高频（128×128）为 39.06，Base 低频 + HyMCNetL3 高频仅 38.80。

结论：
1. V6 的主要短板仍是低频：把 V6 的 128×128 低频换成 HyMCNetL3 的，涨 0.39 dB；换高频只涨 0.08 dB。
2. 在最粗的 16×16 尺度，"V5 低频 + V6 高频"（38.65）不低于 V6 自己（38.64），说明 **V6 的三项编码改动没有让块内低频 Mamba 学到更多结构**，V6 比 V5 多出的 0.13 dB 来自各级细节子带。
3. HyMCNetL3 相对 Base 的优势几乎全在 128 和 64 尺度的低频，与"小波采样改善低频"一致。

## 5. 本周尝试与教训

- **V6 设计**：针对"按行展平的 1D 因果扫描看不到二维结构"这一假设，用编码方式补救而不增加扫描方向——(a) 四个 Haar 子带拼接成 2×2 结构 token；(b) Hilbert 曲线扫描顺序（相邻 token 的二维距离恒为 1，行优先约 126）；(c) Mamba 内部 1D 因果卷积换成 2D 深度卷积。实现与数值验证通过（块初始偏差 0.079，接近恒等映射）。
- **结果**：仅 +0.13 dB（相对 V5），低频没有明显改善，假设只得到很弱的支持。
- **过程中发现的问题**：`Mamba_Model.FFN` 内部自带残差，而块外又加了一次，使得 FFN 支路实际为 `x + LN(x) + ffn(LN(x))`，这是 V4 初始化偏差大的真正原因；V5 起改用 `Model.py` 的无内部残差 FFN。HyMCNetL3 沿用了旧的 FFN，如果修正它，也许还有提升空间，这是尚未验证的点。

## 6. V7：沿光谱维扫描（已实现，待训练）

**动机**：CASSI 的核心耦合在光谱维；空间 1D 扫描在二维图像上结构性受限，而每个像素的波段序列天然有序。

**设计**（`model_v7.py`，相对 HyMCNetL3 **只改一处**）：每个 MambaB 里的空间扫描 `Mamba_Att` 换成 `SpecMamba_Att`——把特征图切成 8×8 窗口，每个窗口得到一条以通道（波长）为序列、每个通道 token 的特征为 64 个像素的序列，Mamba 沿通道方向扫描。空间结构交给 5×5 位置卷积、11×11 的 ConvB 和 U-Net 的多尺度路径。骨架、小波采样、损失、训练配置均不变，因此 HyMCNetL3 与 V7 的对比隔离出"扫描轴"这一个因素。

**已验证**：
- 沿光谱的因果性：扰动第 40 个及以后通道，前 40 个通道输出不变；
- 窗口间互不影响（扫描层面）；
- 参数量 2.95M（HyMCNetL3 为 2.94M），训练一步 0.27 s、峰值显存 10.6 GB，与 HyMCNetL3 持平；前向反向无 NaN。

**风险**：
- 深层通道不再对应物理波段，"光谱因果序"只在第一层严格成立；
- 窗口之间在扫描上互不相通，跨窗口信息完全依赖卷积；
- 若 V7 ≤ HyMCNetL3，则"Mamba 学全局"的收益来自空间扫描而不是光谱扫描，需要重新讨论 Mamba 的角色。

## 7. 下一步计划

1. 训练 V7（约 2 天），按同样流程测试，做频段 SNR 与子带互换，对比 HyMCNetL3 的低频。
2. 修正 HyMCNetL3 的 FFN 双重残差，单独训练一次，量化其影响（可能是廉价的增益）。
3. 若 V7 有效，再考虑"空间 + 光谱"两种扫描的组合；若无效，转为强调"小波采样 + Mamba"的结论，并补充消融。
4. 论文指标用 MATLAB `cal_psnr_ssim.m` 复核 SSIM；测试集只有 10 个场景，0.1~0.2 dB 的差异需谨慎解读。
